# 替音工具

给翻唱做的一个小工具：**把 MV 的画面原样保留，换成你自己的音频。**

全程**不重编码** —— 视频流和音频流是逐字节拷贝过去的，画质音质零损失，处理速度只受硬盘速度限制（不是重新压制，所以几分钟的视频通常十几秒就完）。

---

## 它解决什么问题

常用的"替换视频里的音频"方法是重新压制一遍，画面会掉一代画质，而且这个过程不可逆。本工具换了一条路：

1. 你在 DAW 里按**无损**导出音频（**CAF** / **WAV** / **FLAC** 都可以）；
2. 工具把源视频的第 1 条视频流和你的第 1 条音频流，用 `-c copy` 原样封进一个新的 MKV；
3. 结果：画面一帧没动，声音一比特没动。

这就是它可以做到"零损失"的原因，也是它唯一的原理。

## 使用步骤

### 1. 在 DAW 里导出音频

**推荐这样导出（无损）：**

| 设置项 | 要求 |
|:--|:--|
| 格式 / 容器 | **CAF**（推荐）、**WAV**，或 **FLAC** |
| 编码 | **线性 PCM / Linear PCM / 未压缩**，或 **FLAC**（无损压缩） |
| 位深 | 16 位或 24 位 |
| 采样率 | 与源视频音轨相同最省事（不一定相同也能用） |

**三种无损格式怎么选：**

| 格式 | 说明 |
|:--|:--|
| **CAF** | 推荐。对超长音频支持最稳 |
| **WAV** | 最通用，DAW 都支持。缺点是体积大（5 分钟约 82 MB） |
| **FLAC** | 无损压缩，体积约为 WAV 的一半，工具直接支持 |

这三种装进成品后**都是无损的**，选哪个看你方便。

**有损格式也能用，但成品会有损：**

MP3、AAC(M4A)、Opus、Vorbis、AC3 这些**不会被拒绝**，
但工具会黄字提醒：音频本身已经有损，成品不会比它更好。

> 这是刻意的设计：工具不替你否决，但必须让你知道成品是无损还是有损。

⚠️ **必须导出完整长度**。如果你在 DAW 里裁过片段导致长度对不上，请重新导出，不要用"偏移"硬凑（见下文）。

⚠️ 唯一会被拒绝的编码是 **TrueHD** —— 实测它无法原样封进 MKV。

### 2. 打开工具

解压后双击 `替音工具.exe`。

> 解压后你会看到一个 `bin` 文件夹和一堆 dll 文件。**只管双击 `替音工具.exe`，其他不要删**。
> `bin\ffmpeg.exe` 是核心，删了程序就不能工作。

### 3. 选文件

界面只有两件事：**左右两个框**和**下面一个"开始"按钮**。

- 把视频拖进左边的框，把音频拖进右边的框（也可以点框里的按钮选）
- 框里会立刻显示文件的实际规格：分辨率、帧率、编码、采样率、位深、声道、时长

**这些数字是给你核对的** —— 如果你发现采样率和预期不符，说明 DAW 导出设置选错了，现在改还来得及。

两框中间那条会显示**时长比对**：

| 显示 | 含义 |
|:--|:--|
| `✓ 时长一致　4:12` | 正常，可以直接开始 |
| `≈ 时长基本一致（差 0.2 秒）` | 正常，差别来自帧对齐，不用管 |
| `⚠ 音频短 0:05` | **请自己判断**：如果是有意让结尾静音就没问题；如果是 DAW 导出范围选错了，请重新导出 |

出黄字的时候按钮**依然可以按**。工具不会替你决定对错，只把事实摆出来。如果有需要你留意的地方，会在下面多出一行提醒，右侧有「详情」可以展开看全部。

### 4. 点"开始"

进度条会出现。处理完成后弹出一个窗口，显示输出文件的路径和体积，并有 **打开所在文件夹** / **播放** / **再处理一个** 三个按钮。

点「再处理一个」会清空两个框，可以直接开始下一首。

## 音频偏移（什么时候需要）

偏移是低频功能，所以收在**时长条右侧的「音频偏移」**里（整块都可以点），点开是一个独立窗口。

只要不是两个文件都就绪、时长也一致，这条中间还会出现一句提示，把你引到这个功能上。

只有在一种情况下才需要：**你导出的音频整体比视频早或晚了一点点。**

- 填 **正数** = 音频往后推（晚出现）
- 填 **负数** = 音频往前提（早出现）
- 单位是**毫秒**；输入框右边会同时告诉你等于多少**秒**，不用自己换算

举例：导出时前面多了 0.3 秒静音 → 填 `-300`（也就是 -0.3 秒）。
你发现人声比画面快了 0.5 秒 → 填 `+500`（也就是 +0.5 秒）。

弹窗里有 **预览前 10 秒** 按钮：它会生成一个低清小文件并用系统播放器打开，让你先听一遍确认对齐，再决定要不要正式输出。

设过偏移之后，时长条上那个入口会变成浅绿色，一眼能看出"这次改过偏移"。

**不要用偏移来解决"裁过片段"的问题。** 裁剪造成的长度差异不是"整体偏移"，而是内容对不上，偏移救不了。那种情况请重新导出完整长度。

⚠️ 工具只比对**时长**，不比对**内容**。两个时长完全一致的音频，一个从第 0 秒对齐、一个从第 0.5 秒开始，工具都会告诉你"时长一致" —— 它看不见内容，只有你的耳朵能。

## 输出说明

- **格式固定为 MKV**，界面上没有容器选项（这是为了让流程不可能出错）。
- 只保留**源视频的第 1 条视频流** + **你的第 1 条音频流**，其余全部丢弃：源视频自带的音轨、字幕、章节、封面都会被丢掉。
- 默认保存到**源视频所在目录**，文件名是 `源视频名_替换音频.mkv`；重名会自动加 `(1)`、`(2)`。
- 保存位置在**右上角「设置」**里改。
- **体积会比源视频大一些**，这是正常的：音频以未压缩的 PCM 存储。
  48 kHz / 24 位 / 立体声是 **0.275 MB/秒**，所以 5 分钟的音频约占 **82 MB**
  （3 分钟约 49 MB，10 分钟约 165 MB），大约是源视频里 AAC 的 18 倍。

## 常见问题

**开始按钮是灰的**
说明文件不满足最基本条件。按钮上方会写清楚还差什么，通常是：
- 还没选齐视频和音频；
- 视频文件里没有视频流（可能是纯音频文件）；
- 音频文件里没有音频流；或编码是 TrueHD（实测无法封进 MKV）;<br>　有损编码（MP3/AAC 等）不会拦，只会黄字提醒成品会有损。

**提示找不到 ffmpeg.exe**
请重新解压压缩包。常见原因是压缩软件把 `bin` 文件夹单独放到了别的地方 —— `bin` 必须和 `替音工具.exe` 在同一层。

**提示 ffmpeg 无法运行**
多半是**杀毒软件拦截了 ffmpeg**（它是误报重灾区）。请把程序目录加入杀毒软件白名单，然后到「设置 → 检查运行环境」确认。

**程序直接闪退 / 打不开**
看程序目录下的 `错误日志.txt`，里面记录了原因。

**输出文件在哪？**
完成后弹窗里点"打开所在文件夹"。默认在源视频旁边。

**可以批量处理吗？**
目前不行，一次一个。拖入多个文件时只会使用第一个，状态栏会告诉你忽略了几个。
